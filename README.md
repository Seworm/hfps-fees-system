# Home Field Preparatory School Fees Collection System

A complete web-based school fees management system for Home Field Preparatory School in Ghana.

## Features
- Student Management
- Fees Setup by Class
- Payment Collection
- Automatic Receipt Generation
- Daily/Weekly/Monthly Reports
- Google Sheets Integration

## Deployment
1. Set up Google Sheets (see instructions)
2. Deploy Google Apps Script
3. Update config.js with your script URL
4. Access at: https://[your-username].github.io/hfps-fees-system/
